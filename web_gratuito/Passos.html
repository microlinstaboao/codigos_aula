Introdução

Nesta atividade, você vai criar uma página web simples usando as tags HTML que aprendeu e estilizá-la com CSS. Vamos construir uma página de perfil pessoal.

Primeiramente, abra o Visual Studio Code e crie uma novo arquivo clicando em "File / New Text File / Crie uma nova pasta com nome 'Meu primeiro Projeto'/ abra a pasta / nomeie o primeiro arquivo como 'index.html', por fim, clique em salvar, e inicie o desenvolvimento do HTLM

Dica: Para visualizar o progresso do seu desenvovimento, sempre salve o seu projeto 'CTRL + S' e visualize o resultado atualizando o arquivo index.html.

Tags que vamos utilizar:

  • header - Cabeçalho da página
  • nav - Menu de navegação
  • main - Conteúdo principal
  • section - Seções de conteúdo
  • article - Conteúdo independente
  • aside - Conteúdo relacionado
  • footer - Rodapé
  • h1 a h6 - Títulos
  • p - Parágrafos
  • span - Container genérico inline
  • pre - Texto pré-formatado
  • b, i, u - Formatação de texto
  • small, strong, em, mark - Ênfase e marcação
  • a href - Links
  • target - Atributo para links

Passo 1: Estrutura Básica do HTML

Comece criando a estrutura básica de um documento HTML.

<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Meu Perfil</title> <style> /* Adicionaremos os estilos aqui */ </style> </head> <body> <!-- Conteúdo da página será adicionado aqui --> </body> </html>
⚠️ Digite o código manualmente para melhor aprendizado!
Lembrete: A tag !DOCTYPE html define que este é um documento HTML5. A tag meta charset="UTF-8" define a codificação de caracteres para suportar acentos.

Passo 2: Adicionando a Estrutura Semântica

Agora vamos adicionar as tags semânticas para estruturar nossa página.

<body> <header> <h1>Meu Nome</h1> <p>Desenvolvedor Web Iniciante</p> </header> <nav> <a href="#sobre">Sobre Mim</a> <a href="#interesses">Interesses</a> <a href="#contato">Contato</a> </nav> <main> <section id="sobre"> <h2>Sobre Mim</h2> <article> <p>Olá! Eu sou um estudante de HTML e CSS.</p> </article> </section> <section id="interesses"> <h2>Meus Interesses</h2> <article> <p>Eu gosto de tecnologia, música e esportes.</p> </article> </section> <aside> <h3>Links Úteis</h3> <p><a href="https://www.w3schools.com" target="_blank">W3Schools</a></p> </aside> </main> <footer> <p><small>© 2023 Meu Perfil. Todos os direitos reservados.</small></p> </footer> </body>
⚠️ Digite o código manualmente para melhor aprendizado!
Importante: Note o uso do atributo target="_blank" no link, que faz com que ele abra em uma nova aba.

Passo 3: Adicionando Mais Conteúdo e Formatação

Vamos enriquecer nosso conteúdo com mais tags de formatação.

HTML - Adicione dentro da seção "Sobre Mim":

<article> <p>Olá! Eu sou um <strong>estudante</strong> de HTML e CSS. Estou <em>aprendendo</em> a criar páginas web.</p> <p>Estou fazendo um curso de <mark>HTML e CSS básico</mark> e esta é minha primeira página.</p> <p>Algumas tags que estou aprendendo:</p> <pre> <b>Negrito</b> <i>Itálico</i> <u>Sublinhado</u> </pre> <p>Estou muito <span style="color: blue;">animado</span> com este aprendizado!</p> </article>
⚠️ Digite o código manualmente para melhor aprendizado!

CSS - Adicione dentro da tag style:

body { font-family: Arial, sans-serif; margin: 0; padding: 0; background-color: #f4f4f4; line-height: 1.6; } header { background-color: #2c3e50; color: white; padding: 20px; text-align: center; } nav { background-color: #34495e; padding: 10px; text-align: center; } nav a { color: white; text-decoration: none; margin: 0 15px; } main { padding: 20px; max-width: 800px; margin: 0 auto; } section { background-color: white; padding: 20px; margin-bottom: 20px; border-radius: 5px; } aside { background-color: #ecf0f1; padding: 15px; border-radius: 5px; } footer { background-color: #2c3e50; color: white; text-align: center; padding: 15px; }
⚠️ Digite o código manualmente para melhor aprendizado!
Dica de CSS: Lembre-se de que as cores podem ser personalizadas. Experimente mudar as cores de fundo e texto para criar um design único.

Passo 4: Adicionando Interatividade com JavaScript

Agora vamos deixar sua página interativa usando JavaScript!

HTML - Adicione dentro do <main>:

<section id="interacao"> <h2>Interação</h2> <p>Digite seu nome:</p> <input type="text" id="nomeUsuario" placeholder="Seu nome aqui"> <button onclick="mostrarMensagem()">Mostrar mensagem</button> <p id="mensagem"></p> </section>
⚠️ Digite o código manualmente para melhor aprendizado!

JavaScript - Adicione antes da tag </body>:

<script> function mostrarMensagem() { let nome = document.getElementById("nomeUsuario").value; if(nome === "") { document.getElementById("mensagem").innerText = "Por favor, digite seu nome!"; } else { document.getElementById("mensagem").innerText = "Olá, " + nome + "! Seja bem-vindo!"; } } </script>
⚠️ Digite o código manualmente para melhor aprendizado!
Dica: O JavaScript permite adicionar interatividade à página. A função é executada quando o botão é clicado!
